# Regresi Linear Berganda

Regresi linear berganda adalah pengembangan dari regresi sederhana. Bedanya, metode ini menggunakan lebih dari satu variabel input untuk memprediksi output. Jadi, model ini lebih realistis karena di dunia nyata, biasanya ada banyak faktor yang mempengaruhi hasil.

Contohnya dalam bisnis dropshipping:
Penjualan tidak hanya dipengaruhi oleh budget iklan, tapi juga:

- harga produk
- rating produk
- jumlah review
- kualitas foto produk

Modelnya ditulis seperti:
y = a + b1x1 + b2x2 + b3x3 + ...

Artinya, setiap variabel punya pengaruh masing-masing terhadap hasil.

Contoh:
Jika:

- budget tinggi → menaikkan penjualan
- harga terlalu mahal → menurunkan penjualan
- rating tinggi → menaikkan penjualan

Maka model akan menggabungkan semua itu untuk menghasilkan prediksi yang lebih akurat.

Regresi ini cocok digunakan untuk analisis bisnis, dashboard, dan pengambilan keputusan karena mempertimbangkan banyak faktor sekaligus.
