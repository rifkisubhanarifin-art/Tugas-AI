# Regresi Linear Sederhana

Regresi linear sederhana adalah metode untuk melihat hubungan antara satu variabel input dan satu output. Tujuannya biasanya untuk memprediksi nilai di masa depan berdasarkan pola yang sudah ada. Misalnya, kita ingin tahu apakah budget iklan berpengaruh terhadap jumlah penjualan produk.

Cara kerjanya cukup sederhana. Model akan mencari garis lurus terbaik yang mendekati semua titik data. Garis ini biasanya ditulis dalam bentuk persamaan seperti:
y = a + bx  
Di mana:

- y = hasil (misalnya penjualan)
- x = input (misalnya budget iklan)
- a = nilai awal
- b = pengaruh x terhadap y

Contoh sederhana:
Jika kita punya data:

- 100 ribu → 20 penjualan
- 200 ribu → 40 penjualan

Model akan belajar bahwa semakin besar budget, semakin besar penjualan. Lalu kita bisa prediksi, misalnya jika budget 150 ribu, kira-kira penjualan sekitar 30.

Regresi ini cocok digunakan kalau hanya ada satu faktor utama yang mempengaruhi hasil. Tapi kalau faktor sudah banyak, model ini jadi kurang akurat.
